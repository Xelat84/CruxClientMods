# Changelog

The section matching a release's version is used as that release's GitHub notes (the
auto-generated "What's Changed" list is appended). Headings must contain the bare version, e.g.
`## [0.16]`.

## [0.16]

First release of Crux.

- Added an **auction house**: an in-client window to browse, buy and sell on the server's player
  auction exchange.
- Added **direct connect**: join the server straight from the client, skipping the server browser.
- Added a **bigger action queue**: queue up to 10 crafting actions regardless of your Mind Logic skill.
- Added **recipe examine**: an "Examine" option in the crafting recipe browser that opens an item's
  recipe card.
- Added **item stacking when placing**: place items on top of other items (e.g. stack ingots)
  instead of only on the ground.
- Added a **wider skill column**: the skill window's "Level" column is widened so longer values
  stay readable.
